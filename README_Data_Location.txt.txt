===================================================
      WHALE TRACKER PRO - DATA LOCATION
===================================================

Dear customer,

To let you know where your settings, custom sounds, and operation logs are stored, the application uses a special folder on your computer.

📁 Exact path (Windows):

    %APPDATA%\WhaleTracker

How to access quickly?

1. Open File Explorer.
2. In the address bar, copy and paste exactly this:

    %APPDATA%\WhaleTracker

3. Press Enter.

It will automatically take you to a folder like:

    C:\Users\YOUR_USERNAME\AppData\Roaming\WhaleTracker

Inside you will find:

✅ config.json       → Your configuration (parameters, Telegram, sounds, profiles...)
✅ logs\             → All operation logs (CSV files per day and symbol)
✅ sounds\           → Custom sounds you have uploaded
✅ license.dat       → License file (do not delete it)

Why is it saved there instead of next to the program?

- So that when you update the application (replace the .exe) you DO NOT lose your data.
- So that each user on the same PC has their own configuration.
- So that the application can write files without permission issues.

🔒 Can I delete these files?

- If you delete config.json, the app will revert to factory settings.
- If you delete the logs folder, you will lose the operation history.
- If you delete license.dat, you will need to reactivate the license (if you have questions, contact support).

Important! If you need to back up or transfer your configuration to another computer, just copy the entire WhaleTracker folder.
