===================================================
      WHALE TRACKER PRO - UBICACIÓN DE DATOS
===================================================

Estimado cliente,

Para que sepas dónde se guardan tus configuraciones, sonidos personalizados y registros de operaciones, la aplicación utiliza una carpeta especial en tu computadora.

📁 Ruta exacta (Windows):

    %APPDATA%\WhaleTracker

¿Cómo acceder rápidamente?

1. Abre el Explorador de archivos (carpetas).
2. En la barra de direcciones, copia y pega exactamente esto:

    %APPDATA%\WhaleTracker

3. Presiona Enter.

Automáticamente te llevará a una carpeta como:

    C:\Usuarios\TU_USUARIO\AppData\Roaming\WhaleTracker

Allí encontrarás:

✅ config.json       → Tu configuración (parámetros, Telegram, sonidos, perfiles...)
✅ logs\             → Todos los registros de operaciones (archivos CSV por día y símbolo)
✅ sounds\           → Los sonidos personalizados que hayas subido
✅ license.dat       → Archivo de licencia (no lo borres esta oculto)

¿Por qué se guarda ahí y no junto al programa?

- Para que al actualizar la aplicación (reemplazar el .exe) NO pierdas tus datos.
- Para que cada usuario de la misma PC tenga su propia configuración.
- Para que la aplicación pueda escribir archivos sin problemas de permisos.

🔒 ¿Puedo borrar estos archivos?

- Si borras config.json, la app volverá a la configuración de fábrica.
- Si borras la carpeta logs, perderás el historial de operaciones.
- Si borras license.dat, tendrás que reactivar la licencia (si tienes dudas, contacta con soporte).

¡Importante! Si necesitas hacer una copia de seguridad o transferir tu configuración a otro equipo, solo tienes que copiar toda la carpeta WhaleTracker.

=======================================================
           WHALE TRACKER PRO - DATA LOCATION
=======================================================

Dear customer,

To let you know where your settings, custom sounds, and operation logs are saved, the application uses a special folder on your computer.

📁 Exact path (Windows):

      %APPDATA%\WhaleTracker

How to access it quickly?

1. Open File Explorer (folders).

2. In the address bar, copy and paste exactly this:

         %APPDATA%\WhaleTracker

3. Press Enter.

It will automatically take you to a folder like:

C:\Users\YOUR_USERNAME\AppData\Roaming\WhaleTracker

There you will find:

✅ config.json       → Your settings (parameters, Telegram, sounds, profiles...)
✅ logs\             → All operation logs (CSV files by day and symbol)
✅ sounds\           → The custom sounds you have uploaded
✅ license.dat       → License file (do not delete it, it is hidden)

Why is it saved there and not next to the program?

* So that when updating the application (replacing the .exe), you DO NOT lose your data.
* So that each user on the same PC has their own settings.
* So that the application can write files without permission issues.

🔒 Can I delete these files?

* If you delete config.json, the app will revert to factory settings.
* If you delete the logs folder, you will lose your operation history.
* If you delete license.dat, you will have to reactivate your license (if you have any doubts, contact support).

Important! If you need to make a backup or transfer your settings to another computer, you just have to copy the entire WhaleTracker folder.
